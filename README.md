# KAPORAL INTELLIGENCE — Production

KAPORAL INTELLIGENCE is a premium, AI-assisted and human-supervised global intelligence platform for markets, crypto, macro, options, Africa, business, and technology.

This repository is the production codebase for the KAPORAL INTELLIGENCE platform.

## Core product pillars

- Global market intelligence
- Bitcoin & crypto research
- Macro and monetary policy analysis
- Options & derivatives education/analytics
- Africa intelligence
- Business opportunity intelligence
- Technology and industry research
- K-SCORE editorial prioritization
- KAPORAL Impact Maps
- Prediction Ledger
- Human-supervised agent newsroom

## Stack

- Next.js 16
- React 19
- Supabase Postgres/Auth/Edge Functions
- Vercel deployment target

## Status

The online Supabase backend is active. The application is being migrated into this repository and will be deployed through a reviewed production branch.
