# INTELLIGENCE ATELIER — Design System

KAPORAL INTELLIGENCE should feel like an institutional intelligence terminal, a luxury editorial magazine and a scientific visualization laboratory at the same time.

## Visual principles

- Deep midnight analytical environments alternate with warm ivory editorial surfaces.
- Champagne-gold is reserved for priority, provenance and high-value interaction—not decoration everywhere.
- Glass and dimensional surfaces should create depth without becoming crypto-neon spectacle.
- Large serif editorial typography carries investigations; compact sans-serif typography carries data.
- Charts, maps and diagrams must explain or prove an argument. Decorative charts are prohibited.
- Mobile is designed intentionally, not produced by shrinking desktop.

## Proprietary visual grammar

- KAPORAL Impact Map — causal transmission graph
- KAPORAL Scenario Cone — probability widening over time
- KAPORAL Signal Matrix — direction × confidence × magnitude × horizon
- KAPORAL Evidence Stack — fact / data / inference / field intelligence / opinion
- KAPORAL Disagreement Panel — main thesis vs contrarian thesis
- Consequence Horizon — now / weeks / months / years

## Accessibility

- Maintain readable contrast on all text/data surfaces.
- Never encode risk direction using color alone.
- Interactive graphics need textual fallbacks.
- Reduced-motion preferences must be respected as animation is added.

## Anti-patterns

Do not copy Cointelegraph, Bloomberg, TradingView or crypto-exchange visual language. Avoid generic card walls, excessive white space without hierarchy, neon gradients, random Bitcoin artwork, decorative AI businessmen and gratuitous 3D.
